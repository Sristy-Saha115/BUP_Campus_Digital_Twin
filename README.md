# BUP Digital Twin Application

A comprehensive smart campus digital twin framework integrating real-time bus tracking, AI campus assistant, interactive navigation, slot bookings, blood donor requests, and event management.

## Project Structure

```text
bup-digital-twin/
│
├── static/
│   ├── css/
│   │   └── style.css            # Styling for UI layout and video banner
│   └── js/
│       └── main.js              # Frontend logic for chatbot & API calls
│
├── templates/
│   └── index.html               # Frontend interface
│
├── app.py                       # Flask Backend APIs and Routing
├── database.db                  # SQLite Database (Auto-generated)
├── schema.sql                   # Database setup script
├── requirements.txt             # Project dependencies
